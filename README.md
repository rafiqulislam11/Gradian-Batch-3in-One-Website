# Gradian-Batch-3in-One-Website
## RI Creative Background Studio Ultra Pro

A powerful, high-performance web-based creative studio and batch processing engine for 3-in-one background creation, multi-axis blur engines, 24-tool professional Liquify Studio, 136 3D glass styles, procedural noise textures, and automated Photoshop ExtendScript batch pipelines.

### Key Features
- **3-Panel Layout Generator:** Custom split measurements, Golden Ratio, symmetrical & asymmetrical cropping, pan & zoom, and slot swapping.
- **Photoshop Blur Engine:** 20 direct pixel-level blur filters with mathematical incremental accumulator formula and zero underlying ghosting.
- **Professional Liquify Studio Pro:** Full Photoshop-style 24-tool interactive warp engine (Forward, Twirl CW/CCW, Pucker, Bloat, Push Left, Reconstruct, Smooth, Freeze/Thaw masking, Face & Body Reshape, Mesh Warp, Bulge 3D, and Custom Brush) running at 60 FPS via WebGL GPU acceleration.
- **136 3D Glass & Optical Lighting Engine:** Ribbed, fluted, reeded, prism, crystal, and procedural refractions.
- **100+ Noise & Film Grain Presets:** Real-time texture synthesis with blend modes.
- **Non-Destructive Layer Manager:** Unlimited practical layers with blend modes, opacity, and real-time composite stack.
- **Desktop & Mobile Responsive:** 100% responsive across Desktop (1080p, 2K, 4K), Laptop (1366x768, 1440x900), Tablet, and Mobile devices.
- **Photoshop Batch Script (ES3):** `ri_creative_batch_studio_pro_fixed.jsx` for processing thousands of images automatically in Adobe Photoshop.
